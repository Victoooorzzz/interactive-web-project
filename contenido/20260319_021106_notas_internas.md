**Requisitos Iniciales (del brief):**
Profesional o equipo para el desarrollo e implementación de una línea telefónica dedicada al escucha emocional. Abarca desde la conceptualización técnica hasta la puesta en marcha operativa del servicio.

**Cualificación y Requisitos Detallados (tras llamada de descubrimiento simulada):**

**1. Objetivo Principal del Proyecto:**
Crear una plataforma integral y robusta para una línea de escucha emocional, que permita a individuos buscar apoyo confidencial y accesible. El objetivo es ofrecer un servicio gestionado por un equipo de "oyentes" capacitados, garantizando un funcionamiento fluido desde la conceptualización técnica hasta la operación diaria.

**2. Funcionalidades Clave Identificadas:**
*   **Sistema de Gestión de Llamadas (VoIP):** Implementación de una infraestructura VoIP que permita el enrutamiento inteligente de llamadas, colas de espera, y funcionalidades básicas de telefonía para conectar a los usuarios con los oyentes disponibles.
*   **Plataforma de Oyentes:** Una interfaz web/aplicación para que los oyentes puedan:
    *   Gestionar su disponibilidad y horario.
    *   Acceder al historial de llamadas y sesiones.
    *   Tomar notas durante o después de las llamadas (con garantía de privacidad y confidencialidad).
    *   Acceder a recursos y guías de apoyo.
*   **Panel de Administración:** Un backend robusto para la gestión centralizada que incluya:
    *   Supervisión de estadísticas y métricas de uso del servicio.
    *   Gestión de usuarios (oyentes y administradores).
    *   Configuración del sistema (horarios de operación, mensajes de bienvenida, etc.).
    *   Posibilidad de expansión para futuras funcionalidades (ej. reportes, análisis de sentimiento).
*   **Experiencia de Usuario:** Interfaz intuitiva y fácil de usar para los usuarios finales que buscan apoyo emocional.

**3. Oportunidad de Software Identificada:**
Desarrollo de una **plataforma web/aplicación full-stack** que integre un sistema de comunicación (VoIP), un CRM personalizado para la gestión de oyentes y sesiones, y un panel de administración para la operación y supervisión del servicio.

**4. Tecnologías Potenciales Sugeridas (para propuesta técnica):**
*   **Backend:** Python (FastAPI o Django)
*   **Frontend:** React, Angular o Vue.js
*   **Base de Datos:** PostgreSQL
*   **Comunicación (VoIP):** Integración con servicios como Twilio o implementación de Asterisk/FreeSWITCH.

**5. Plazo Estimado:**
El cliente busca una primera versión funcional (MVP - Producto Mínimo Viable) en un plazo de 3 a 4 meses.

**6. Presupuesto:**
El cliente está abierto a una propuesta detallada que refleje el alcance y las funcionalidades definidas. El presupuesto inicial de "Más de USD 45 / hora" sirve como referencia para la tarifa, pero se necesita un presupuesto de proyecto cerrado.
